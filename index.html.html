What I found, and how to fix it

Three vulnerability types from my code review, explained for someone who isn't a security specialist.

Plaintext password storage

Passwords were stored exactly as typed. Anyone who reads the file reads every password. Fix: store a salted hash made with a slow algorithm such as bcrypt or Argon2, never the password itself.

Hardcoded credentials

Login details written directly into the source code travel with every copy of it. Fix: keep secrets in environment variables or a secrets manager, and rotate anything that was exposed.

Unsanitized input handling

Input was used without checking it, which lets attackers send data the program never expected. Fix: validate length, type and format on every input, and reject anything outside the rules.
